# Transcribo skill

Agent skill for [Transcribo](https://transcribo.es/): turn audio and video files into text with speaker labels, in Spanish and 60 languages in total, up to 4 hours per file.

```bash
npx skills add santigamo/transcribo-skill --skill transcribo
```

The skill teaches your agent to use the Transcribo MCP server at `https://api.transcribo.es/mcp`. You sign in with a [transcribo.es](https://transcribo.es/) account, and the first 30 minutes are free.

See [`skills/transcribo/SKILL.md`](skills/transcribo/SKILL.md) for the full instructions.
